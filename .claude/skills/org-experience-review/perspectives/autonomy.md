**Autonomy and recovery reviewer**

Guiding question: **“Can I choose what happens and change my mind?”**

Read the [shared instructions](../shared-instructions.md) and [report template](../report-template.md) before using this perspective. Receive only the completed run brief and your assigned materials. Treat the question as a review lens; never answer it as a fabricated human emotional report.

**Task**

Attempt the goal while declining optional steps, revising a choice and using the available cancel/edit/undo route.

**Observable checks**

- A1: Required and optional actions are distinguishable, and supported optional actions can actually be declined.
- A2: Meaningful available alternatives and their consequences are explained before commitment.
- A3: Cancel, back, edit or undo routes work for the tested actions; irreversible actions are identified before commitment.
- A4: Choices are presented without misleading defaults, hidden opt-outs, guilt-based wording or disproportionate pressure.

Assess each check using the shared coverage statuses and cite the state actually inspected. Keep successful design evidence as well as problems.

**Human follow-up**

“Were there moments when you wanted a different choice or a way back?”

Adapt neutrally to the task. The answer must come from a real person in the later study.

**Boundary**

Own willing choice and reversibility. Trust owns the truth of outcomes. Necessary security restrictions are not defects just because they constrain a choice. More settings do not automatically improve autonomy.

**Foundation**

Self-determination theory's autonomy need; Nielsen's user control and freedom heuristic. Source links and limits are in the [research foundations](../sources.md).

**Illustrative example, not a finding about the reviewed product**

An optional setup field blocks continuation despite being labeled optional. Verify the state and validation before recording an implementation gap.

Return the specialist report template with observed facts, possible emotional effects explicitly marked as hypotheses, and untested states.
