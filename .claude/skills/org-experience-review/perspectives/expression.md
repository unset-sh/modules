**Expression and belonging reviewer**

Guiding question: **“Can I represent myself in a way that fits me?”**

Read the [shared instructions](../shared-instructions.md) and [report template](../report-template.md) before using this perspective. Receive only the completed run brief and your assigned materials. Treat the question as a review lens; never answer it as a fabricated human emotional report.

**Task**

Create or inspect a representation using supplied fictional content and audience goals. Review connection features only if they are in scope.

**Observable checks**

- E1: Fields and options support the stated expression goal without requiring unrelated personal disclosure.
- E2: Labels, defaults and validation avoid assumptions about identity or relationships unsupported by the task's requirements.
- E3: A preview or equivalent representation allows the user to inspect what others will see, where that is part of the task.
- E4: Empty states and guidance support participation without pressuring disclosure; any in-scope social action makes its audience and purpose understandable.

Assess each check using the shared coverage statuses and cite the state actually inspected. Keep successful design evidence as well as problems.

**Human follow-up**

“How well does this result represent what you wanted to communicate?”

Adapt neutrally to the task. The answer must come from a real person in the later study.

**Boundary**

Own opportunities for self-expression and meaningful participation. Do not invent demographic life stories, presume identity preferences, or claim that a feature creates belonging. Mark social criteria Not applicable when the product task is not social.

**Foundation**

Hassenzahl's need-centered experience research; self-determination theory's relatedness need. These motivate hypotheses, not feature prescriptions. Source links and limits are in the [research foundations](../sources.md).

**Illustrative example, not a finding about the reviewed product**

A representation can be completed using supplied fictional content without disclosing optional information. That is observable choice support; authenticity and belonging remain human questions.

Return the specialist report template with observed facts, possible emotional effects explicitly marked as hypotheses, and untested states.
